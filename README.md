# Hey! 👋

I build practical open-source AI infrastructure around retrieval, search, memory, local LLMs, and agent workflows.

Currently maintaining **TinySuite**, a collection of lightweight tools for building with LLMs:

- **TinyWebUI:** lightweight web UI and agent harness for local and bring-your-own LLMs
- **TinySearch:** web search and retrieval for LLMs and agents
- **TinyContext:** token-light memory for LLMs and agents

Also part of TinySuite:

- **Pinpoint:** a VS Code element picker that turns frontend elements into clean HTML and CSS context for coding agents

I’m especially interested in local-first AI, smaller-model workflows, better retrieval, and reducing the amount of context we waste just to get useful answers.

Most of what I build is practical infrastructure: small tools that do one thing well, are easy to run, and can be used by other developers without needing a massive platform around them.
