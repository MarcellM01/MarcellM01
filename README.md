# Hey! 👋

I’m an AI engineer building practical open-source infrastructure for retrieval, agents, memory, and local LLM workflows.

Currently maintaining **TinySuite**, a collection of lightweight tools for building with LLMs:

- **TinyWebUI:** lightweight web UI and agent harness for local and bring-your-own LLMs
- **TinySearch:** fast, token-efficient web search and retrieval for LLMs and agents
- **TinyContext:** token-light memory for LLMs and agents

Also part of TinySuite:

- **Pinpoint:** agent-agnostic VS Code tooling for passing precise frontend element context to coding agents

I’m especially interested in local-first AI, smaller-model workflows, retrieval pipelines, context management, agent tooling, and reducing the amount of context we waste just to get useful answers.

Most of what I build is practical infrastructure: small tools that solve a specific problem well, are easy to run, and can be used by other developers without needing a massive platform around them.

I mostly work with **Python, JavaScript/TypeScript, FastAPI, Docker, OpenTelemetry, vector search, and modern LLM APIs**.
